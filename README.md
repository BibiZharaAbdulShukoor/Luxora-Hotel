# LUXORA — Final Home Page

A premium hotel homepage built with only:
- HTML5
- CSS3
- Vanilla JavaScript

## Structure

LUXORA-Hotel-Final-Home/
├── index.html
├── css/
│   ├── style.css
│   └── responsive.css
├── js/
│   └── main.js
└── images/

## Included

- Luxury cinematic hero
- Responsive navigation
- Mobile hamburger menu
- Light / Dark mode with localStorage
- Sticky glass navbar
- Booking date validation
- Night calculation
- Scroll reveal animation
- Room cards
- Experience section
- Philosophy section
- Gallery
- Full gallery lightbox with previous/next controls
- Testimonial slider + autoplay
- Custom desktop cursor
- Toast notifications
- Responsive mobile/tablet/desktop layout

## Run

Open the folder in VS Code and use Live Server, or open index.html directly.
The demo images are remote Unsplash images, so an internet connection is needed for them.
