LUXORA HOTEL — Luxury Hotel Website

A modern, elegant, and responsive luxury hotel website built using HTML5, CSS3, and Vanilla JavaScript. Luxora Hotel provides an immersive browsing experience with interactive features, elegant animations, and a responsive layout designed for desktop, tablet, and mobile devices.

Features

Home Page & User Interface

- Cinematic hero section with luxury hotel imagery
- Modern and elegant user interface
- Sticky glass-effect navigation bar
- Responsive navigation menu
- Mobile hamburger menu
- Custom desktop cursor
- Smooth scrolling and scroll reveal animations

Booking Experience

- Interactive booking form
- Check-in and check-out date validation
- Automatic calculation of the number of nights
- Form validation and user feedback
- Toast notifications for important actions

Room & Hotel Sections

- Room cards showcasing hotel accommodations
- Hotel experiences section
- Hotel philosophy section
- Image gallery featuring hotel interiors and experiences

Interactive Gallery

- Full-screen image lightbox
- Previous and next image navigation
- Interactive gallery controls

Testimonials

- Testimonial slider
- Automatic slide transitions
- Interactive testimonial presentation

Theme & Responsiveness

- Light and dark mode
- Theme preference saved using localStorage
- Responsive layouts for desktop, tablet, and mobile screens
- Dedicated responsive CSS styles

Technologies Used

Technology Purpose
HTML5 Website structure and content
CSS3 Styling, layouts, animations, and visual effects
Vanilla JavaScript Interactivity, form validation, and dynamic behavior
LocalStorage Saving the user’s theme preference

Getting Started

Follow these steps to run the project locally.

1. Clone or Download the Project

Download the project files and extract them into a folder on your computer.

2. Open the Project

Open the project folder in Visual Studio Code.

3. Run the Website

You can run the website using either method:

- Recommended: Install the Live Server extension in VS Code, open index.html, and select Open with Live Server.
- Alternative: Open index.html directly in your web browser.

4. Internet Connection

An internet connection is required to display the remote demonstration images hosted on Unsplash.

Responsive Design

Luxora Hotel is designed to adapt to different screen sizes, providing a consistent browsing experience across:

- Desktop computers
- Tablets
- Mobile phones

Project Goals

The main goal of this project is to demonstrate practical front-end development skills by combining semantic HTML, modern CSS techniques, and JavaScript interactivity to create an elegant hotel website.

The project focuses on responsive design, user experience, interactive components, form validation, and clean project organization.
